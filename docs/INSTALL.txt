FocusTrace 설치 안내
====================

필요 환경: macOS 13 Ventura 이상. Apple Silicon(M1 이상)·Intel Mac 모두 지원.
Xcode, 개발 도구, 계정, 브라우저 확장 프로그램은 필요하지 않습니다.

1. 받은 DMG 파일을 더블클릭합니다.
2. FocusTrace.app을 옆의 Applications 폴더로 드래그합니다.
3. 복사가 끝나면 DMG를 추출하고, 응용 프로그램 폴더에서 FocusTrace를 엽니다.
   DMG 안에서 바로 실행하지 마세요. 자동 실행 등록 전에 설치 위치를 정하세요.

처음 실행할 때 macOS가 차단한다면
--------------------------------
Build info.txt에 공증되지 않았다고 적혀 있는 버전은 macOS 경고가 나올 수 있습니다.
보낸 사람과 파일 출처를 확인한 경우에만 다음 절차로 허용하세요.

- 응용 프로그램 폴더에서 한 번 실행을 시도한 뒤 경고를 닫습니다.
- 시스템 설정 → 개인정보 보호 및 보안 → 보안에서 FocusTrace의
  '확인 없이 열기'(Open Anyway)를 선택하고 안내에 따라 인증합니다.
- 다시 열기를 확인합니다. 버튼은 실행 시도 후 약 1시간 동안 표시될 수 있습니다.

'손상됨' 또는 악성 코드 경고가 나오면 이 절차로 무시하지 말고 보낸 사람에게
새 파일을 요청하세요. 회사에서 관리하는 Mac은 관리자의 허용이 필요할 수 있습니다.
Apple 안내: https://support.apple.com/ko-kr/102445

처음 사용할 때
--------------
- 실행하면 전면 앱의 사용 시간을 자동으로 기록합니다.
- 사이트별 기록: Settings → General → Website tracking을 켜고 Chrome 또는
  Safari를 선택합니다. 그 브라우저를 사용하면 macOS가 자동화 접근을 요청합니다.
  허용하면 활성 탭의 사이트를 구분합니다. 거부했다면 시스템 설정 → 개인정보 보호
  및 보안 → 자동화에서 FocusTrace의 해당 브라우저를 허용하고 앱에서 Retry를 누르세요.
- 화면 녹화·손쉬운 사용 권한은 필요하지 않습니다.
- Settings → General → Launch at login으로 로그인 시 자동 실행할 수 있습니다.
- 창을 닫아도 기록은 계속됩니다. 종료: 메뉴 막대 아이콘 → Quit FocusTrace.

기록과 개인정보
--------------
기록은 이 Mac에만 저장됩니다. 계정과 사용 기록 업로드 기능은 없습니다.
앱 식별자·사이트 호스트·시간을 저장하며 전체 URL, 페이지 내용, 키 입력은 저장하지
않습니다. 사이트 아이콘을 가져올 때는 해당 사이트에 HTTPS 요청이 발생합니다.
시크릿 창도 브라우저가 주소를 제공하면 기록될 수 있습니다.
5분간 입력이 없으면 이후 시간을 제외합니다. 이 기준은 Settings에서 바꿀 수 있습니다.

업데이트·삭제
-------------
자동 업데이트는 없습니다. 새 DMG를 받으면 메뉴 막대에서 기존 앱을 종료하고,
응용 프로그램 폴더의 앱을 새 버전으로 교체합니다. 기록은 유지됩니다.
교체 전에 Settings → Privacy & data → Backups → Manage…에서 백업할 수 있습니다.
서명이 바뀐 버전은 자동화 권한을 다시 허용해야 할 수 있습니다.

삭제: Launch at login을 끄고 앱을 종료한 다음 응용 프로그램 폴더에서 휴지통으로
옮깁니다. 앱 삭제만으로 기록·백업은 지워지지 않습니다. 기록까지 지우려면 Finder의
이동 → 폴더로 이동에서 아래 폴더를 열어 삭제하세요. 이 작업은 되돌리기 어렵습니다.
  ~/Library/Application Support/FocusTrace/
  ~/Library/Application Support/FocusTrace Backups/
아이콘 캐시: ~/Library/Caches/FocusTrace/
