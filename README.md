# FocusTrace

Mac에서 사용 중인 모든 전면 앱과 지원 브라우저의 웹사이트 사용 시간·방문 횟수를 기록하는 SwiftUI 앱입니다. 집중을 방해하는 서비스는 따로 선택해 필터링할 수 있습니다. 기록은 Mac에 저장되며 계정이나 서버가 필요하지 않습니다.

## 빌드와 실행

- 실행: macOS 13 이상
- 빌드: macOS, Swift 6.0 이상과 macOS SDK (Xcode 16 이상 또는 해당 Command Line Tools)
- 외부 패키지 의존성 없음

```sh
git clone https://github.com/devnjw/yolo.git
cd yolo
swift test
zsh build.sh
open dist/FocusTrace.app
```

빌드 스크립트는 아이콘을 생성하고 현재 Mac 아키텍처용 실행 파일을 `.app`으로 묶어 ad-hoc 서명합니다. **실행 중인 FocusTrace를 종료한 후 빌드하세요.** Developer ID 서명·공증을 거친 배포용 빌드는 아닙니다. Swift 패키지는 Swift 5 언어 모드를 사용합니다.

## 사용법

1. 앱을 실행하면 추적이 시작됩니다. 창을 닫아도 메뉴 막대에서 계속 동작하며, 메뉴 막대의 **Quit FocusTrace**로 종료합니다.
2. 전면에서 사용하는 앱과 사이트는 **Services**에 자동으로 추가됩니다. 같은 서비스로 확인된 앱·도메인은 한 행으로 묶이고, **Distracting** 열의 번개 버튼으로 서비스 전체를 선택합니다. 이름을 누르면 포함된 앱·사이트·별칭을 확인할 수 있습니다. 더보기 메뉴의 **Add distraction…**으로 아직 사용하지 않은 앱·도메인도 미리 선택할 수 있습니다. 기존 추적 대상과 기본 목록(KakaoTalk, LinkedIn, Instagram, YouTube)은 방해 서비스로 이어받으며 언제든 해제할 수 있습니다.
3. 웹사이트별 기록은 **Settings → Website tracking**을 켜고 Chrome·Safari를 선택해야 합니다. 모든 HTTP/HTTPS 사이트를 자동 등록하며, 주소를 읽을 수 없는 탭이나 다른 브라우저는 브라우저 앱 사용 시간으로 기록합니다. 앱과 사이트 시간을 중복으로 더하지 않습니다. macOS가 요청하면 자동화 접근을 허용합니다. 화면 녹화·손쉬운 사용 권한이나 확장 프로그램은 필요하지 않습니다.
4. **Overview**는 선택한 방해 서비스의 **Distracted time**과 **Visits**를 보여줍니다. Day는 합계, Week·Month·Year는 기록 근거가 있는 완료된 날짜의 하루 평균입니다. 오늘과 기록이 없는 날짜는 평균에서 제외하고, 다른 활동만 기록된 날짜나 추적기가 실행된 근거가 있는 0분 날짜는 포함합니다. 평균의 시간·횟수·서비스 목록은 같은 분모를 사용합니다. Year의 월별 막대도 하루 평균이며 연간 값은 날짜 수로 가중합니다.
5. 기간 탭과 날짜 이동으로 범위를 고릅니다. 그래프는 Day의 시간별, Week·Month의 일별, Year의 월별 활동을 보여줍니다. 막대를 누르면 목록과 상세 기록만 해당 구간으로 좁혀지고 상단 값은 유지됩니다. 현재 날짜의 일별 막대는 진행 중인 합계를 표시합니다. 데이터가 없는 구간은 0분과 구분합니다.
6. **Services**는 기간과 관계없는 서비스 관리 목록입니다. 이름순으로 표시하며 서비스 이름, 앱 식별자, 도메인, 별칭으로 검색할 수 있습니다. 날짜·유형 필터와 시간·방문 통계는 이 화면에 표시하지 않습니다. **Overview**의 순위와 방문 상세는 같은 서비스의 기록을 합산하고, **Manage services**로 관리 화면에 이동합니다. 더보기의 CSV 내보내기는 전체 원본 기록을 포함하며 시각은 UTC ISO 8601입니다.

Overview의 방문 상세에서도 서비스 전체의 방해 여부를 바꿀 수 있습니다. 선택은 과거·향후 기록의 필터에 함께 적용되며, 해제해도 수집은 계속됩니다. 이전에 제거한 대상도 다시 사용하면 기존 ID로 기록합니다. 같은 서비스의 다른 구성원이 선택돼 있으면 서비스 설정을 이어받습니다. 업데이트 이전에 수집하지 않은 앱·사이트 기록은 소급 생성하지 않습니다.

**Settings → Launch at login**은 macOS `SMAppService`로 자동 실행을 등록합니다. 등록한 앱의 위치를 유지하세요. 브라우저 접근이 거부되면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 허용한 뒤 해당 브라우저의 **Retry**를 누릅니다. 로컬 서명이 바뀌면 macOS가 권한을 다시 요청할 수 있습니다.

## 측정 기준

- 앱이나 사이트로 전환하면 방문 1회입니다. 같은 사이트 안의 페이지 이동은 같은 방문입니다. 서비스로 묶어도 원본 방문을 합치거나 다시 쓰지 않으므로 같은 서비스의 앱↔웹 전환은 각각의 방문으로 남습니다. Overview의 시간·방문 수는 구성원 기록의 합계입니다.
- 서비스 통합은 명시적인 앱 bundle ID와 도메인 목록을 사용합니다. ChatGPT, Figma, GitHub, Instagram, LinkedIn, Notion, Slack, Spotify, VS Code, YouTube를 인식하며, 목록에 없는 서비스는 개별 항목으로 유지합니다. 비슷한 이름만으로 자동 병합하지 않고, 수동 병합 기능은 아직 없습니다. 기존 구성원의 방해 선택이 다르면 하나라도 선택된 경우 서비스 전체를 선택 상태로 이어받습니다. 새로 발견된 구성원도 해당 설정을 따릅니다.
- 약 1초 간격으로 전면 앱·활성 탭을 확인합니다. 수 초의 경계 오차나 짧은 방문 누락이 있을 수 있으며, 실제 시선이나 업무 목적을 판단하지 않습니다.
- 기본값은 5분간 입력이 없으면 그 시점부터 중단합니다. 앞선 5분은 포함됩니다. 영상 시청처럼 입력 없는 이용도 제외될 수 있으며 Settings에서 기준을 바꿀 수 있습니다.
- 잠자기·화면 잠금·비활성 세션에서는 중단합니다. 지연된 샘플 사이의 긴 시간을 채워 넣지 않습니다. 약 5초마다 저장하므로 비정상 종료 시 최근 기록 일부가 유실될 수 있습니다.
- 방문 횟수는 시작 날짜에 귀속하고 시간은 날짜별 겹치는 구간으로 나눕니다. 날짜는 Mac의 현재 시간대 기준이며, 서머타임의 반복 시간은 같은 시간대 막대에 합칩니다.
- Quick checks는 종료된 방문 중 전체 길이가 30초 이하인 기록입니다. 진행 중인 방문은 제외합니다.
- 사이트는 호스트명으로 자동 등록하며 `www.`와 마지막 점을 정규화합니다. 기존 도메인과 별칭은 하위 도메인을 포함하며, 여러 대상이 겹치면 가장 구체적인 도메인을 선택합니다. localhost·IP 주소도 기록합니다. 브라우저 앱의 방해 선택은 사이트로 분리되지 않은 앱 시간에 적용됩니다.
- 시크릿 창도 브라우저가 활성 탭 주소를 제공하면 측정됩니다. 시크릿 창 자동 제외 기능은 없습니다.

## 데이터와 개인정보

`~/Library/Application Support/FocusTrace/`에 저장합니다.

| 파일 | 내용 |
| --- | --- |
| `visits.json` | 방문 ID, 대상 ID, 시작·종료 시각 |
| `sources.json` | 이름, 앱 식별자 또는 사이트 호스트, 별칭, 방해 여부, 이전 버전의 제외 상태 |
| `coverage.json` | 추적기가 실행되어 샘플을 확인한 시간 구간. 활동 없는 기록일과 데이터 없는 날짜를 구분 |

이전 버전의 문자열 ID와 Foundation JSON 날짜 형식을 그대로 읽습니다. 방해 여부가 없는 이전 목록은 활성 대상을 선택 상태로, 제거된 대상을 해제 상태로 읽어 저장합니다. 자동 발견된 새 대상은 기본적으로 방해 서비스가 아니며, 이미 선택한 서비스의 구성원이라면 그 선택을 이어받습니다. 폴더는 `0700`, 파일은 `0600` 권한으로 저장하며, 읽기·기록 오류가 발생하면 추적을 중단합니다. 읽지 못한 기존 기록은 덮어쓰지 않습니다. 세 파일을 함께 백업하세요. 방문 기록과 기록일 정보를 초기화하려면 앱 종료 후 `visits.json`과 `coverage.json`을 삭제합니다. 이전 버전에서 coverage 파일이 없는 날짜는 기존 방문 기록을 기록 근거로 사용합니다. 이는 하루 전체 수집을 보증하지 않으며, 과거에 선택된 서비스만 수집한 기록은 그대로 제한된 범위입니다. 기록이 없던 과거 날짜를 0분으로 소급 생성하지 않습니다.

전체 URL은 메모리에서 대상 분류에만 사용하며 사이트 호스트만 저장합니다. bundle ID가 없는 앱은 실행 파일 경로를 식별자로 사용합니다. 페이지 제목·내용·메시지·스크린샷·키 입력 내용은 저장하지 않으며, 분석 SDK나 사용 기록 업로드 기능이 없습니다. 표시·브라우저 설정은 UserDefaults에 저장됩니다.

앱 아이콘은 로컬에서 읽습니다. 웹사이트 아이콘은 해당 사이트의 공개 홈페이지·아이콘 주소에 HTTPS 요청으로 가져옵니다. 브라우저 쿠키·인증 정보는 사용하지 않으며, 제3자 아이콘 검색 서비스는 사용하지 않습니다. 아이콘 서버에는 일반적인 네트워크 요청 정보가 전달됩니다. 아이콘은 `~/Library/Caches/FocusTrace/WebsiteIcons/v2/`에 캐시하고, 실패하면 기존 캐시 또는 기본 아이콘을 표시합니다.

## 코드 구조

| 위치 | 역할 |
| --- | --- |
| `Sources/TrackingCore/` | 대상 분류, 방문 집계, 일별·시간별 통계, JSON 저장, CSV 생성. UI와 독립적인 Foundation 코드 |
| `Sources/TrackingCore/ServiceGroup.swift` | 서비스 식별·그룹화·선택 동기화. 원본 ID와 기록은 유지 |
| `Sources/FocusTrace/Tracker.swift` | macOS 이벤트·타이머와 추적 상태 조정 |
| `Sources/FocusTrace/BrowserTabReader.swift` | 백그라운드 Apple Events 호출과 URL 분류 |
| `Sources/FocusTrace/Dashboard.swift` | 화면 이동, Overview 날짜와 Services 검색 상태, 대화상자 관리 |
| `Sources/FocusTrace/*View.swift`, `VisitDetail.swift` | 개요·목록·설정·추가·상세 화면 |
| `Sources/FocusTrace/InterfaceStyle.swift` | 공통 여백·글자 크기·컨트롤 스타일 |
| `Sources/FocusTrace/WebsiteIconLoader.swift` | 제한된 크기의 아이콘 다운로드와 캐시 |
| `Tests/TrackingCoreTests/` | 추적 규칙, 날짜 경계, 저장 호환성·실패, CSV 및 아이콘 후보 검증 |

대시보드는 기간별 결과를 만들어 요약·차트·서비스 목록에서 공유합니다. 시간은 선택 구간에 맞춰 잘라 집계하고 방문은 시작 시각에 귀속합니다. 저장소는 기존 방문·대상 JSON과 ID를 보존하며, 실행 근거는 별도 coverage 파일로 저장합니다. 앱 식별자도 기존 설치의 설정·권한 호환을 위해 유지합니다.

`Resources/AppIcon.png`가 앱 아이콘 원본이며 `scripts/build-icon.sh`가 `.icns`를 생성합니다. 빌드 산출물, 로컬 설정, 사용 기록은 Git에서 제외합니다.

## 검증

```sh
swift test

```

GitHub Actions에서도 테스트와 release 패키징·서명 검증을 실행합니다. 테스트는 실제 macOS 자동화 권한, 잠금·잠자기 이벤트, 로그인 자동 실행을 대신하지 않습니다. 이 동작은 빌드한 앱에서 확인해야 합니다.
